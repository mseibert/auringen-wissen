# Rahmeninfos zum Auringer Weinstand

|  |  |
|----|----|
| Motto | Jeden Freitag ein anderer Wein von einem anderen Verein. |
| Ort | Direkt vor der Gemeindeverwaltung |
| Tag | Freitags |
| Zeitpunkt | In der Regel ab 18 Uhr abends |
| Teilnehmer | etwa zwischen 50 und 400 Personen |
| Getränke | in der Regel Wein, manchmal Bier, Softdrinks, Wasser, ... |
